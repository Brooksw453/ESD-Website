The rule: DOJ set the ADA Title II web and document date at April 26, 2027 for large entities, which includes public colleges, and April 26, 2028 for small entities and special districts. The rule’s standard is WCAG 2.1 AA; everything here is checked against 2.2, which includes it. Use the window to do this right. Read the rule →
