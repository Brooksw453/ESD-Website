What Document Ally Pro does

Preflight, remediate, and keep the record.

Upload a Word file or a PDF. Preflight shows the accessibility score and top issues at no cost, including untagged PDFs, scanned pages, poor OCR, and multi-column layouts. Remediation adds heading structure, alt text on images, descriptive link text, and real lists, with an OCR pass first on scanned PDFs. You get back a tagged PDF and a Word file, with the score before, what changed, and a verified score after, re-checked on the file that was actually produced.

  • Tagged PDF plus Word back for every file
  • Before/after record, re-verified on the output file
  • Free preflight score before you spend a credit
  • Batch upload: several documents in one run
  • 8 preview themes, including high contrast and dyslexia-friendly
  • Output checked against WCAG 2.2 AA and Section 508
  • FERPA-friendly: documents are not stored by default
  • Signed-in accounts with row-level security
